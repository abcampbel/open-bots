# Code of Conduct

We want OpenBots to be a welcoming project for everyone, regardless of background or experience.

**Expected:** be respectful and patient, assume good intent, give constructive feedback on code rather
than on people, and credit others' work.

**Not acceptable:** harassment, insults or personal attacks, discriminatory language, publishing others'
private information, and sustained disruption of discussions.

**Enforcement:** maintainers may edit or remove comments, commits and issues that break these rules, and
may temporarily or permanently ban contributors. Report problems privately to the maintainers through
[GitHub Security Advisories](https://github.com/alexvladimirovich888/agnes123/security/advisories/new) or by
contacting a maintainer directly. Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
